# Subrat Das — Premium Portfolio + Admin CMS

Modern recruiter-ready portfolio with Admin CMS. Built with React 19, TypeScript, Vite, Tailwind CSS v4, Framer Motion, React Router, Supabase, Vercel Functions.

## Live
- Portfolio: https://subratdas.vercel.app
- Admin: https://subratdas.vercel.app/admin/login

## Features
- Public: Hero, About, Skills, Experience, Projects, Resume, Contact, AI Assistant, GitHub integration
- Admin: Dashboard, CMS for all sections, Page Builder, Messages, Analytics (visitor intelligence, delete/highlight), Audit Logs

## Tech Stack
React 19 | TypeScript | Vite 7 | Tailwind CSS v4 | Framer Motion | React Router | Supabase | Vercel

## Structure
api/, src/components/{admin,public,ui}/, src/lib/, src/pages/, supabase/
